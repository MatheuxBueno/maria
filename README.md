# Vesper — Kink Jars

Site estático independente, em português, com tema gótico-vampírico.

## Arquivos
- `index.html`: estrutura da página
- `css/style.css`: visual e responsividade
- `js/app.js`: itens, avaliações, salvamento local e exportação PNG

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e pastas mantendo esta estrutura.
3. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

Não precisa de Node.js, build ou dependências externas. O salvamento usa o `localStorage` do navegador e não sincroniza entre aparelhos.
